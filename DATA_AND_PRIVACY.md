# Data and Privacy

Guardian's core checks run locally on the user's device. Guardian sends no checked content to the owner and collects no product telemetry for the owner.

The User Vault stores only files placed there by the user. Vault contents are encrypted at rest with local key material. Loss of the operating-system keychain entry or fallback key can make stored content unrecoverable.

The local status widget exposes a device-local service for status and control. Guardian does not publish that service to the internet.

Guardian can run inside or alongside third-party AI products. Text submitted to those products remains governed by their own terms, privacy notices, administrator settings, and retention controls. Guardian does not change the provider's handling of that content.

License keys are validated locally. Support requests remain user-directed and can include only the diagnostic material the user chooses to provide.
