# Guardian v2.8.25 Review Candidate

This private review candidate packages Guardian for Windows, macOS, compatible Claude plugin hosts, and prompt-only use.

## Highlights

- Provides a Windows no-dependency installer with a bundled Node.js runtime.
- Supports targeted Windows setup for Claude Desktop, Codex, VS Code, and the Copilot alias.
- Adds install, repair, uninstall, report, quiet, and target-selection paths.
- Includes the local Guardian widget and client lifecycle launcher.
- Packages the Claude plugin, standalone installer, and prompt kit from one build source.
- Restores the bundled macOS installer entrypoint and includes its version and legal documents.

## Assets

The release contains six product packages:

- `guardian-enterprise-v2.8.25.plugin`
- `guardian-standalone-v2.8.25.zip`
- `guardian-prompt-kit-v2.8.25.zip`
- `guardian-windows-standalone-v2.8.25.exe`
- `guardian-windows-standalone-v2.8.25.cmd`
- `guardian-windows-standalone-v2.8.25.zip`

Build evidence and `SHA256SUMS.txt` accompany the product packages.

## Validation

The release candidate passed archive inspection, Windows payload inspection, installer license tests, deterministic license-fixture checks, an isolated install-repair-uninstall dry run, and an MCP stdio smoke test.
