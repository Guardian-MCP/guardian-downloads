# Guardian v2.8.26

Guardian v2.8.26 expands the Windows standalone release path and repairs the vault UI test isolation that blocked the complete server gate.

## Highlights

- Adds Windows install, repair, uninstall, quiet, report, and target-selection paths.
- Preserves unrelated Claude Desktop, Codex, and VS Code MCP configuration during setup changes.
- Adds graceful Claude Desktop restart handling and keeps `--no-restart` available.
- Adds version and product metadata to the compiled Windows EXE.
- Verifies EXE argument forwarding and temporary extraction cleanup.
- Restores the standalone macOS installer entrypoint and includes the version and legal documents in its archive.
- Isolates vault UI folder exports inside the test fixture so the full test suite does not write to the user's Documents folder.

## Release packages

The release contains six product packages:

- `guardian-enterprise-v2.8.26.plugin`
- `guardian-standalone-v2.8.26.zip`
- `guardian-prompt-kit-v2.8.26.zip`
- `guardian-windows-standalone-v2.8.26.exe`
- `guardian-windows-standalone-v2.8.26.cmd`
- `guardian-windows-standalone-v2.8.26.zip`

Build evidence and `SHA256SUMS.txt` accompany the packages.

## Validation

- The complete server gate passed, including lint, type checks, formatting, tests, property checks, and MCP inspection.

- Main archive and Windows payload inspections passed.
- Installer license and deterministic fixture checks passed.
- Isolated install, repair, uninstall, and target-selection tests passed.

- The Windows standalone audit passed 141 checks with no failures. Explorer double-click and SmartScreen behavior remain manual VM coverage.
